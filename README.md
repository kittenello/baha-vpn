# бахза впн

впн-клиент для ios 17+ на базе xray-core для подключения к своим серверам и подпискам.

что уже есть:

- vless, vmess, trojan, shadowsocks, hysteria2 и wireguard.
- tls, reality, vision; tcp, websocket, grpc, httpupgrade и xhttp.
- импорт ссылок, qr-кодов, файлов и конфигураций xray json.
- подписки с обновлением и поддержкой привязки устройства через hwid.
- список серверов, поиск, избранное и проверка tcp-задержки.
- правила маршрутизации, выбор dns и обход локальной сети.
- шифрованное хранение профилей и подключение через системный впн ios.
